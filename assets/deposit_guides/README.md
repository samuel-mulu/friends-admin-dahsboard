# Deposit guide screenshots

Replace the placeholder PNGs with portrait phone screenshots for each provider.

## Required files

| Provider | Files |
|----------|-------|
| Telebirr | `telebirr/step_1.png`, `step_2.png`, `step_3.png` |
| CBE | `cbe/step_1.png`, `step_2.png`, `step_3.png` |
| Awash | `awash/step_1.png`, `step_2.png`, `step_3.png` |
| BOA | `boa/step_1.png`, `step_2.png`, `step_3.png` |

Recommended size: ~360×640 px (portrait). The app shows a placeholder if an image is missing.
